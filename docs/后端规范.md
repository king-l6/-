# 后端规范

本文档为「后端、API、接口、服务端」相关问题的技能文档。当用户问题包含上述字眼时，回答与实现必须遵循本规范。

---

## 技术栈

- **框架**：Flask（Python）
- **入口**：`app.py`，路由与 API 在此定义

## API 约定

- REST 风格：GET 查询、POST 提交；返回 JSON 时使用 `jsonify`
- 错误处理：接口异常时返回明确错误信息与合适 HTTP 状态码（如 400、500）
- 与前端配合：若前端用 fetch，后端需设置 CORS 或同源部署，返回 JSON 结构稳定

## 代码与结构

- 业务逻辑可放在单独模块（如 `strategy_engine.py`、`data_fetcher.py`），`app.py` 主要负责路由与请求响应
- 配置、密钥等不写死在代码中，使用环境变量或配置文件
- 涉及数据库或外部 API 时，做好异常捕获与日志
