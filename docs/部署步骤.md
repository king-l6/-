# 部署步骤（上线清单）

按顺序执行以下步骤，即可把 A 股策略回测系统部署到公网（本机 + Cloudflare 隧道）。

---

## 一、首次部署（或代码/依赖有变更时）

### 1. 安装依赖并构建

在**项目根目录**执行：

```bash
./run.sh
```

首次会创建虚拟环境、安装 Python 与前端依赖、构建前端并启动服务。**先按 `Ctrl+C` 停止**，再继续下一步。

若需分步执行：

```bash
python3 -m venv venv
source venv/bin/activate          # Windows: venv\Scripts\activate
pip install -r requirements.txt
cd frontend && npm install && npm run build && cd ..
```

### 2. 启动本机服务

在**项目根目录**执行：

```bash
./run.sh
```

或（已激活虚拟环境且前端已构建）：

```bash
source venv/bin/activate
python3 app.py
```

在浏览器打开 [http://localhost:8086](http://localhost:8086)，确认能访问。

### 3. 暴露到公网

**新开一个终端**（不要关掉运行服务的终端），执行：

```bash
cloudflared tunnel --url http://localhost:8086
```

终端会输出类似：

```text
https://xxxx-xx-xx-xx-xx.trycloudflare.com
```

用手机或其它设备浏览器打开该 **HTTPS** 链接即可外网访问。

## 二、日常再次上线（依赖未改）

1. **终端一**（项目根目录）：`./run.sh` 或 `source venv/bin/activate && python3 app.py`
2. **终端二**：`cloudflared tunnel --url http://localhost:8086`，用终端里给出的新链接访问

---

## 三、数据与回测（可选）

若需要更新回测结果数据，在项目根目录执行（详见 [常用命令.md](./常用命令.md)）：

- **日常只补「最后日期之后」的 T 日（推荐）**  
  `python3 scripts/backtest_append_from_last.py`

- **缓存落后时先补缓存再补 T 日**  
  `python3 scripts/update_cache_and_backtest.py --no-backtest`  
  然后执行上一条命令。

- **补全结果文件中的涨跌幅/振幅**  
  `python3 scripts/enrich_results_from_cache.py`

## 四、环境要求

- **cloudflared**：Mac 用 `brew install cloudflared`，Windows 从 [cloudflared releases](https://github.com/cloudflare/cloudflared/releases) 下载并加入 Path

## 六、出现「无法访问此网站」时排查

按下面顺序检查：

1. **本机服务是否在跑**  
   在运行 `cloudflared` 的**同一台电脑**上，浏览器打开 [http://localhost:8086](http://localhost:8086)。  
   - 若**打不开**：说明 Flask 没起来。先去**项目根目录**开一个终端执行 `./run.sh` 或 `source venv/bin/activate && python3 app.py`，等出现 `Running on http://0.0.0.0:8086` 后再用浏览器访问 localhost:8086，能打开再试外网链接。  
   - 若**能打开**：本机正常，再看下面。

2. **cloudflared 必须用「本次」生成的链接**  
   每次执行 `cloudflared tunnel --url http://localhost:8086` 都会给一个**新的** `https://xxxx.trycloudflare.com` 链接，旧链接会失效。用当前终端里**新出现**的那条链接在手机或外网浏览器里打开。

3. **隧道命令建议用 localhost**  
   文档里写的是 `cloudflared tunnel --url http://localhost:8086`。若你改成 `http://10.23.186.44:8086`（本机局域网 IP），需确认本机在 8086 端口已监听（例如先能访问 http://10.23.186.44:8086）。同一台机跑服务时，用 `http://localhost:8086` 即可。

4. **防火墙**  
   若本机 localhost:8086 能访问，但隧道链接仍打不开，检查系统防火墙是否拦截了 cloudflared 或 8086 端口（可暂时关闭防火墙试一次）。

5. **网络**  
   用手机流量访问隧道链接，排除家里 WiFi/路由器限制。
