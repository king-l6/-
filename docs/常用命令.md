## 补差值缓存 + 回测命令

在项目根目录执行。

运行下面命令前，建议先激活虚拟环境：

```bash
source venv/bin/activate  # Windows: venv\Scripts\activate
```

- **一条命令：自动分片补缓存 + 增量回测（推荐日常使用）**

  补缓存与增量回测都用同一分片数并行，只改 `--auto-shard-count` 即可。例如 4 分片：

```bash
python3 scripts/update_cache_and_backtest.py --incremental --auto-shard-count 4
```

  - **步骤 1**：自动起 4 个子进程并行补齐缓存（按股票分区，互不覆盖）。
  - **步骤 2**：缓存完成后，再自动起 4 个子进程并行跑增量回测（只补「最后日期+1」到今天的 T 日），结果自动合并回各策略结果文件。
  - 想改分片数时只改数字即可，如 `--auto-shard-count 2` 或 `--auto-shard-count 6`。片数不是越多越好，一般 2～4 即可，过多可能受 API/CPU 限制反而变慢。

- **补齐缓存 + 全部预设策略全量回测（推荐首次/断档时跑一次）**

```bash
python3 scripts/update_cache_and_backtest.py
```

- **只补齐缓存，不跑回测**

```bash
python3 scripts/update_cache_and_backtest.py --no-backtest
```

- **调整拉取数据并发数（默认 100）**

```bash
python3 scripts/update_cache_and_backtest.py --workers 100
```

## 日常该执行哪个？（你已有六个战法结果文件时）

**推荐：只补「最后日期之后」到今天的 T 日，全部预设战法一起写回各自结果文件（已优化为按股票只加载一次 K 线，速度快）：**

```bash
python3 scripts/backtest_append_from_last.py
```

- 脚本会自动读预设战法结果文件里的最大 match_date，取最小值作为「最后日期」，只回测「最后日期 + 1」到「最近交易日」之间的每个 T 日 × 预设策略，结果追加到各自 `策略名_结果.jsonl`。
- 若提示缓存早于回测截止日，先补缓存再跑：
  ```bash
  python3 scripts/update_cache_and_backtest.py --no-backtest
  python3 scripts/backtest_append_from_last.py
  ```
- 可选：追加完成后若希望结果文件里带齐「匹配日/次日/第三日」涨跌幅与振幅，再跑一次：
  ```bash
  python3 scripts/enrich_results_from_cache.py
  ```

**不需要**再日常跑全量 `update_cache_and_backtest.py`（会重算全部历史，慢），除非你清空了结果或换了策略想重算。

## 只跑回测（全部预设战法）

- **从结果文件“最后日期”补到今天（全部预设战法一起，结果写进各自 `策略名_结果.jsonl`）**

```bash
python3 scripts/backtest_append_from_last.py
```

- **不检查缓存是否最新，直接回测（缓存未更新时也可跑）**

```bash
python3 scripts/backtest_append_from_last.py --no-check-cache
```

- **指定并发线程数（默认 50）**

```bash
python3 scripts/backtest_append_from_last.py --workers 50
```

- **只回测最近一个交易日 T（不看历史结果文件）**

```bash
python3 scripts/incremental_backtest.py
```

## 多策略同日汇总（读已有结果、生成新文件）

在**各策略已回测并写入** `results/策略名_结果.jsonl` 之后，按「同一 `match_date`」跨策略找股票，生成**新文件**（不覆盖原策略结果）。

- **重叠 overlap（默认）**：某日某股在 **≥2 个策略**（可用 `--min-strategies` 改）里同时出现即输出；每行有 **`overlap_strategies` / `overlap_strategies_text` / `overlap_summary`**（写明重叠的是哪几个策略），另有 `strategies` 等同义字段；**同一交易日内**按命中策略数从多到少排序，再按代码升序。
- **全交集 intersection**：该日该股在**全部**参与扫描的策略里都有命中（策略很多时往往为空）。
- **并集 union**：该日任意策略命中即可列出，用 `--min-strategies` 过滤至少 N 个策略（默认 1）。

```bash
# 默认：重叠，至少 2 个策略同日命中 → results/多策略同日_重叠.jsonl
python3 scripts/aggregate_same_day_multi_strategy.py

# 至少 3 个策略同日命中
python3 scripts/aggregate_same_day_multi_strategy.py --min-strategies 3

# 全交集（全部参与策略均命中）
python3 scripts/aggregate_same_day_multi_strategy.py --mode intersection

# 并集：列出所有命中，不限策略数
python3 scripts/aggregate_same_day_multi_strategy.py --mode union --min-strategies 1

# 只扫部分策略文件
python3 scripts/aggregate_same_day_multi_strategy.py --strategies 主力建仓 龙头战法 断板反包 --out results/三策略同日_重叠.jsonl
```

## 用缓存补全结果文件（涨跌幅/振幅）

结果文件里已有 code、match_date，但可能缺少「匹配日/次日/第三日」的 day1_amplitude、day1_change_pct、day2_*、day3_*。  
用本地 `cache/stock_data` 的 K 线按 code+match_date 匹配后计算并**写回**原文件：

```bash
# 处理 results 下所有 .jsonl
python3 scripts/enrich_results_from_cache.py

# 只处理指定文件
python3 scripts/enrich_results_from_cache.py --file 龙头战法_结果.jsonl

# 只统计可补全条数，不写回
python3 scripts/enrich_results_from_cache.py --dry-run
```

## 游资三件套参数扫描

新增脚本：`scripts/scan_yzr_params.py`  
用于自动扫描「游资首板试错 / 游资分歧转一致 / 游资二波加速」的关键参数组合，并输出：
- 样本数
- 次日胜率
- 次日均收益
- 第三日均收益

常用命令：

```bash
# 扫描全部游资三件套参数（默认并发50，展示TOP10）
python3 scripts/scan_yzr_params.py

# 调整并发与展示数量
python3 scripts/scan_yzr_params.py --workers 30 --top 15

# 只扫描某一个家族
python3 scripts/scan_yzr_params.py --family "游资分歧转一致"

# 扫描后将全局前3名自动写入 common_strategies.json
python3 scripts/scan_yzr_params.py --promote-top 3
```

扫描结果会额外保存到：

`results/param_scan_yzr_YYYYMMDD_HHMMSS.json`

若使用 `--promote-top`，会在 `common_strategies.json` 末尾自动追加参数优选策略，名称形如：

`游资分歧转一致-参数优选1-YYYYMMDD`

## 多终端：每个终端单独跑一个策略

适合想**同时跑多个策略、互不抢资源**（每个策略一个进程）。

1. **开多个终端**  
   - Cursor / VS Code：`Ctrl+Shift+`` 或菜单 **Terminal → New Terminal** 多开几个；也可 **Terminal → Split Terminal** 分屏。
2. **每个终端在项目根目录执行一条命令**（只跑一个策略，串行）：

| 终端 | 命令 |
|------|------|
| 1 | `python3 batch_backtest.py --strategies "龙头战法" --no-parallel` |
| 2 | `python3 batch_backtest.py --strategies "断板反包" --no-parallel` |
| 3 | `python3 batch_backtest.py --strategies "均线上穿" --no-parallel` |
| 4 | `python3 batch_backtest.py --strategies "情绪周期" --no-parallel` |
| 5 | `python3 batch_backtest.py --strategies "三连板" --no-parallel` |
| 6 | `python3 batch_backtest.py --strategies "筑底突破" --no-parallel` |

每个策略的结果仍会写到 `results/策略名_结果.jsonl`。可先 `--no-backtest` 补一次缓存，再在 6 个终端里同时跑上面 6 条命令。

## 批量回测全部策略（仅本地缓存、不拉网）

前提：`cache/stock_list.json` 与 `cache/stock_data/*.json` 已齐。

```bash
cd /path/to/量化 && source venv/bin/activate
python3 -u batch_backtest.py --cache-only --no-parallel --workers 100 2>&1 | tee "backtest_cache_only_$(date +%Y%m%d_%H%M%S).log"
```

- `--cache-only`：`ensure_sufficient_data` 跳过；K 线只读本地；股票列表仅用 `stock_list.json`（过期也会用）；交易日历从本地 K 推导，不调行情。
- 只重算**某一个**策略（仍只读缓存）：`python3 batch_backtest.py --strategies 主力建仓 --cache-only --no-parallel --workers 100`
- 需要「窗口内每个命中日都落盘、日频=当日真实命中数」时，在以上命令中加 **`--all-match-dates`**（结果行数会变多）。
- 本地策略全跑完后，若要**多策略同日汇总**，再执行：`python3 scripts/aggregate_same_day_multi_strategy.py`

## 情绪周期判断（全市场温度）

脚本：`scripts/emotion_cycle.py`  
根据本地主板日线缓存的**全市场**涨跌结构输出当前情绪周期：
- 冰点
- 弱修复
- 中性震荡
- 强势主升
- 高潮/过热

使用命令：

```bash
python3 scripts/emotion_cycle.py

# 忽略滚动缓存，全量重扫股票日线后再算
python3 scripts/emotion_cycle.py --force
```

说明：建议先执行补缓存命令，确保判断基于最新交易日数据。
