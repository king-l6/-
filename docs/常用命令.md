# 常用命令

以下均在**项目根目录**（本仓库根）执行。未特别说明时，用项目自带解释器即可：

```bash
cd "/path/to/量化"   # 换成你的本机路径
./venv/bin/python batch_backtest.py --cache-only
```

若已 `source venv/bin/activate`，也可把 `./venv/bin/python` 换成 `python3`。

---

## 1. 直接跑「当前配置里的全部策略」回测（最常用）

策略列表以根目录 **`common_strategies.json`** 为准。结果写入 **`results/策略名_结果.jsonl`**。

**全量回测（会打网拉数/检查数据是否够，除非配合 `--cache-only`）：**

```bash
cd "/path/to/量化" && ./venv/bin/python batch_backtest.py
```

**只读本地 `cache/stock_data`，不访问 AkShare（适合缓存已齐、只想重算回测）：**

```bash
cd "/path/to/量化" && ./venv/bin/python batch_backtest.py --cache-only
```

**改并发（默认每策略 50 线程）：**

```bash
cd "/path/to/量化" && ./venv/bin/python batch_backtest.py --cache-only --workers 30
```

**只跑其中某一个策略：**

```bash
cd "/path/to/量化" && ./venv/bin/python batch_backtest.py --cache-only --strategies "主力建仓"
```

**窗口内「每个命中日」一行（日频图口径）：** 在以上命令后加 `--all-match-dates`。

---

## 2. 先补缓存，再跑回测（一条命令）

**补差值缓存 + 按配置跑全量回测：**

```bash
cd "/path/to/量化" && ./venv/bin/python scripts/update_cache_and_backtest.py
```

**只补缓存、不回测：**

```bash
cd "/path/to/量化" && ./venv/bin/python scripts/update_cache_and_backtest.py --no-backtest
```

**补缓存 + 增量回测（看各策略结果文件最后日期，只补缺失 T 日；推荐多分片）：**

```bash
cd "/path/to/量化" && ./venv/bin/python scripts/update_cache_and_backtest.py --incremental --auto-shard-count 4
```

拉数并发可调：`--workers 50`（默认 100）。

---

## 3. 已有缓存时：只增量回测（不写全量）

按各策略 `results/策略名_结果.jsonl` 里的最大 `match_date`，只回测「最后日期 + 1」到最近交易日，**追加**到原文件：

```bash
cd "/path/to/量化" && ./venv/bin/python scripts/backtest_append_from_last.py
```

指定并发：`--workers 50`。不检查缓存是否最新：`--no-check-cache`。

若提示缓存不够新，先：`./venv/bin/python scripts/update_cache_and_backtest.py --no-backtest`，再跑上一条。

---

## 4. 删 cache 后按「新浪日 K + 同花顺概念/行业」重建近 N 交易日

（会清空整个 `cache/`，可用 `--keep-emotion` 保留情绪周期 JSON；详见脚本 `--help`。）

```bash
cd "/path/to/量化" && ./venv/bin/python scripts/rebuild_cache_recent_sina_ths.py --days 30 --workers 40 --keep-emotion
```

多分片只拉个股时加 `--task-index` / `--task-count`；全部分片跑完后**再**执行一次：

```bash
cd "/path/to/量化" && ./venv/bin/python scripts/rebuild_cache_recent_sina_ths.py --board-only --days 30 --no-wipe
```

**板块 `daily` 按「交易日」拆成多进程（每进程只建列表里连续一段日期，常用来 30 进程各 1 天）：** 须已 `--board-only` 且个股日 K 已齐。`--days` 与 `--board-shard-total` 一般取相同（如 30），`--board-shard-index` 从 `0` 到 `total-1`。

```bash
# 示例：30 个并行，各跑 1 个交易日（注意机器负载与接口限流）
cd "/path/to/量化"
for i in $(seq 0 29); do
  ./venv/bin/python scripts/rebuild_cache_recent_sina_ths.py --board-only --days 30 --no-wipe \
    --board-shard-index "$i" --board-shard-total 30 --hist-sleep 0.08 &
done
wait
```

## 5. 其它一行命令（按需）

| 用途 | 命令 |
|------|------|
| 只把「今天」当 T 日扫一遍（按日结果文件） | `./venv/bin/python scripts/incremental_backtest.py` |
| 用本地 K 线补全结果里的涨跌幅/振幅等 | `./venv/bin/python scripts/enrich_results_from_cache.py` |
| 多策略同日重叠汇总（读已有 jsonl 写新文件） | `./venv/bin/python scripts/aggregate_same_day_multi_strategy.py` |
| 情绪周期（读全市场缓存） | `./venv/bin/python scripts/emotion_cycle.py` |
